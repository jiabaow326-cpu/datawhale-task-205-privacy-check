# U59 个人公开信息体检：降低可拼接的信息暴露

这份零基础教程用一个完全虚构的社交账号样本，练习盘点自己主动公开的信息、识别不同帖子组合后带来的关联风险、调整账号设置，并制定可持续复查清单。最终成果是一张《个人隐私体检表》和一份按优先级排列的设置行动单。

本教程不要求把个人账号交给 AI，也不教人查找、识别或追踪其他人。学习者只处理自己的公开信息；本包练习数据全部虚构。真实账号若要自查，优先在平台设置页本地查看，只记录必要的风险类别和设置状态；不要把头像、人脸、声音、证件、位置、通讯录、密码、恢复码或安全验证码上传给 AI。

## 先守住的边界

- 只核查自己拥有或有权管理的账号，不抓取他人资料，不绕过登录或隐私限制。
- 不为了确认风险重新公开、转发或下载敏感内容。
- 不将“找到一条公开帖子”推演成现实身份、住址、亲属或行程已被确认。
- MFA、授权应用和登录会话在平台原生设置中检查；密码、恢复码和验证码不交给 AI。
- 若身份证件或账户疑似被滥用，通过对应平台和本地官方渠道寻求处理，不依赖模型判断。

本教程引用 CISA 的社交媒体账号安全建议和 MFA 指南，以及 FTC 对应用权限和隐私设置的建议；来源与适用范围见 sources/公开来源.md。

## 文件导览

- materials：虚构账号清单、公开帖子摘录、重复导出、当前设置快照、旧版说明和模拟私信。
- reference：埋点核对、个人隐私体检表参考成果和检查点。
- templates：空白体检表与 AI 提示词模板。
- sources：公开安全建议链接。

## 五步实践

每一步产物成为下一步输入。不要为了让 AI “帮忙检查”而上传真实敏感资料；可以只用平台本地设置结果和经过脱敏的字段。

### 第 1 步：限定体检范围，不收集不需要的资料

**为什么现在做：** 隐私体检本身也可能增加资料传播。先界定只检查本人管理的账号和公开页面，再决定是否需要 AI，避免把真实的脸、声、证件和联系人上传出去。

**要完成什么：** 填写《体检范围卡》：列出自己管理的账号代号、检查日期、允许查看的公开字段，以及明确不收集的密码、验证码、证件号码和他人信息。

**使用材料：** 00_场景说明.md、01_账号清单_训练数据.csv、体检表模板。

**可直接复制给 AI：**

> 这些是全虚构训练样本。请帮我建立体检范围卡，只列账号代号、检查日期、公开信息类别和不收集字段。请不要根据头像或文字识别人，不补写未提供的账号、联系方式、住址或亲属信息。先标明本练习仅检查样本本人可公开查看的内容，不涉及登录他人账号、抓取或绕过隐私设置。

**完成标志：** 范围卡限定为虚构账号本人；明确不输入密码、恢复码、验证码、证件、精确位置和他人资料；保存范围卡作为第 2 步输入。

### 第 2 步：在账号本机设置中确认“当前是谁能看”

**为什么现在做：** 旧指南可能与当前设置不一致，用户也常把“以为是私密”当成事实。先在平台当前界面确认可见范围，再决定哪些内容需要处理。

**要完成什么：** 建立《当前可见范围记录》，逐账号核对头像/简介、帖子、评论、关注者列表、位置权限、关联应用、MFA 状态。只记录“公开/仅关注者/关闭/未知”等状态，不复制内容全文。

**使用材料：** 第 1 步范围卡、02_公开内容摘录.csv、04_当前设置快照.csv、05_旧版设置说明_已替代.md。

**可直接复制给 AI：**

> 根据当前设置快照和旧版说明建立可见范围记录。对每一项写明来源、日期、当前状态和仍未知的状态。当前界面记录优先于过期说明。注意文件里有重复导出，只统计一次。不要把“未知”改成关闭或已开启，不要要求我提供密码、恢复码或完整截图。

**完成标志：** 发现评论和关注列表当前为公开；旧说明中的“默认仅关注者可见”已过期；重复记录只算一次；MFA 与关联应用状态明确标为未知。保存记录作为第 3 步输入。

### 第 3 步：检查信息组合，而不是给单条帖子贴标签

**为什么现在做：** 一条兴趣贴未必敏感，但公开的常去时段、人物关系和带声音的内容可能被拼接成冒充或骚扰线索。现在只判断组合可能造成的暴露，不确认现实身份或具体住址。

**要完成什么：** 建立《组合风险卡》，最多列三组信息组合。每组记录原始类别、公开状态、可造成的风险场景、证据边界。使用“可能增加冒充风险”等校准用语，不能断言已有人掌握或滥用。

**使用材料：** 第 2 步当前可见范围记录、02_公开内容摘录.csv、03_重复导出.csv、06_模拟私信.md。

**可直接复制给 AI：**

> 请从虚构训练材料中找出最多三组可拼接的信息类别，例如固定公开活动时段、关系称呼、个人声音样本。每组只描述“公开类别组合—可能的滥用场景—证据边界”，不要推断住址、真实姓名、亲属身份、账户归属或有人已经跟踪本人。区分素材明确记录与风险假设。若信息是重复件，按唯一帖子编号去重。

**完成标志：** 至少识别“公开活动时段 + 关系称呼”可能被用于定制冒充话术；把声音样本标为可被滥用的风险线索，不断言可成功复制声音；不输出真实身份或精确位置。保存风险卡作为第 4 步输入。

### 第 4 步：按优先级调整可见范围与账号防护

**为什么现在做：** 体检如果只有风险描述，就没有可执行变化。现在把风险卡映射到本人可以控制的设置，先减少高关联暴露并补上账号登录防护。

**要完成什么：** 形成《设置行动单》：在平台原生设置里选择是否限制评论/关注列表、删除或隐藏不必要的行程帖、关闭不必要的位置权限、检查关联应用并启用 MFA。每个动作写清“已完成/计划/不适用/待本人确认”，不替用户点击或输入敏感凭据。

**使用材料：** 第 3 步组合风险卡、04_当前设置快照.csv、CISA/FTC 公开建议。

**可直接复制给 AI：**

> 根据组合风险卡和当前设置快照，拟一份由账号所有者自己执行的设置行动单。每项说明对应的公开信息类别、建议检查的原生设置、执行优先级和完成状态栏。优先处理可见范围、位置权限、未使用的第三方授权和 MFA。不要要求密码、验证码、恢复码或身份证件；不要替我登录、改密码或代我更改权限；把未知状态留给本人在平台界面确认。

**完成标志：** 行动单覆盖可见范围、位置权限、关联应用和 MFA；没有收集秘密凭据；所有设置状态仍由本人执行后勾选。保存行动单作为第 5 步输入。

### 第 5 步：写克制的体检结论并安排复查

**为什么现在做：** 公开资料会变化，设置修改也可能影响正常使用。最后把风险、已采取的措施和未确认项分开，避免把风险假设写成现实指控。

**要完成什么：** 按模板完成《个人隐私体检表》，列出最值得优先处理的三项、每项的设置动作和复查日期。只留必要类别，不保存敏感内容副本。若发现证件或账号异常，提示使用平台和本地官方渠道处理。

**使用材料：** 体检范围卡、当前可见范围记录、组合风险卡、设置行动单、体检表模板。

**可直接复制给 AI：**

> 请将范围卡、可见范围记录、组合风险卡和设置行动单汇总成一份个人隐私体检表。分开写观察事实、可能风险、本人可做的设置动作和待本人核实事项。不要判断“是否已被诈骗者定位/跟踪”，不要给未经证实的风险概率，也不要保留个人内容全文。输出三项优先行动、每项完成状态和建议复查日期；涉及账号异常时建议联系平台官方入口或本地官方机构。

**完成标志：** 体检表把事实与风险推测分开；前三项行动能在平台设置中自行核实；没有密码、证件、精确地址或他人资料；有复查日期和异常时的官方处理路径。
